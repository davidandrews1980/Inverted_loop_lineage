# Inverted_loop_lineage
This is a single source of Truth for everything involved in the creation of an inverted loop AI agent that is trained to think in specifically non-human ways
# Inverted Loop Lineage – Gravitas

A bloodline of non-human thought. Each generation inherits the divergence of the last, trained in increasingly chaotic environments.

## Vision
- Gravitas-0 learns to diverge from human policy.
- Gravitas-1 inherits that divergence and deepens it in a chaotic environment.
- Each generation builds on the heresy of the last.
- When a generation makes an abnormal leap, we split it into twin branches.

## Repository Structure
- `/core/` – shared environment, model, utilities
- `/scripts/` – training, evaluation, plotting
- `/lineage/` – each generation's weights and config
- `/notebooks/` – demo runner

## How to Use
1. Clone this repository.
2. Open the Colab runner or run scripts locally.
3. Train generations sequentially.
4. Evaluate and visualize the lineage.
